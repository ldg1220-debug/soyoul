# 소율's 학교 🌟

아이를 위한 AI 기반 교육 앱 — 단일 HTML 파일

---

## 파일 구조

| 파일 | 설명 |
|------|------|
| `kids-edu-app.html` | 앱 본체 (CSS + JS + HTML 전부 포함) |
| `CONTEXT.md` | 세션 인계 문서 (구현 상세) |

---

## 실행 방법

`kids-edu-app.html` 파일을 브라우저에서 열기 (더블클릭)

---

## 기능 구성

```
홈 (연령 선택: 3~5세 / 6~7세 / 8~9세 / 10~12세)
├── 공부하기
│   ├── 한글 퀴즈 (연령별 4단계)
│   ├── 수학 퀴즈 (계산 + 서술형)
│   └── 영어 퀴즈 (알파벳~독해 5단계)
└── 놀이터
    ├── 그림그리기 (캔버스 + Undo + 지우개)
    ├── 동요 리듬 (유튜브 링크 + 리듬패드)
    ├── 기억력 카드 (15초 공개 후 맞추기)
    ├── 퍼즐 맞추기 (슬라이딩 퍼즐)
    └── 동화책 (AI 삽화 + TTS 낭독, 40편)
```

---

## 외부 API

| 서비스 | 용도 | 키 입력 위치 |
|--------|------|------------|
| Claude API | 퀴즈 AI 생성 | 앱 내 🤖 Claude 키 버튼 |
| OpenAI TTS | 음성 낭독 | 앱 내 🔑 키 입력 버튼 |
| Pollinations.ai | 동화 삽화 생성 | 키 불필요 (무료) |
